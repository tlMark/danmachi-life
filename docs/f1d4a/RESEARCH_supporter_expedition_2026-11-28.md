## 2. 설계 반영

| 항목 | 처리 |
|---|---|
| D-2(`supporter_route` 불변식 예외) | **게임 고유 규칙 그대로 둔다.** S-1 은 같은 파밀리아 서포터의 원정 동행을 뒷받침하지만, 원문을 대조하기 전에는 등급을 올리지 않는다. 원문이 확인되어도 등급을 바꾸는 일은 사용자 승인 대상이다(원작 미확인 사항의 확정) |
| `supporter_route` 문구("소속 파밀리아의 원정대가…") | 변경 없음. S-1 과 모순되지 않는다 |
| 직종 분리(Gemini 권고) | 현재 데이터가 이미 분리돼 있다. `JOB_LABELS` 에서 서포터(`supporter`)·대장장이(`blacksmith`)·치유사(`healer`)는 서로 다른 직업이다. 같은 직종으로 통합하는 코드는 없다. "전투원(보급 겸임)" 직업은 없으며 새로 만들지 않는다 |
| 연합 원정의 복수 서포터 규칙 | 구현하지 않는다(설계·승인 없음). 나중에 구현하면 게임 고유 규칙으로 표기한다(S-4 미확인) |
| 코드·시험·결과 | 변경 0 |
